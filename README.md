# MiemTube Frontend

## Сайт
Сайт доступен по ссылке: https://videohosting.miem.tv/ui/

## Описание

Платформа для хранения и распространения видеофайлов под названием "Видеохостинг МИЭМ". Ключевыми особенностями сервиса являются автоматическая запись аудиторных занятий, удаление беззвучных фрагментов, интеграция с внутренними сервисами МИЭМ, а также ролевая модель управления доступом, позволяющая гибко распределять права на запись видео.

## Технологии

- HTML, CSS, JS
- React
- Axios
- Tailwind CSS
- Vite

## Статус

Проект находится в активной разработке. В скором времени планируется переписать на TypeScript. В качестве системы управления версиями используется Gitlab, здесь находится копия проекта, которая периодически обновляется.
